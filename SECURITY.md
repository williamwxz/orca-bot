# Security

## Reporting a problem

Please do not open a public issue for a security problem. Use **Report a
vulnerability** on this repository's Security tab on GitHub. You should get a
reply within a week.

Say what you did, what happened, and which versions of Orca, Orca Bot and
OpenMausBot you use. Do not include sign-in codes, tokens or private messages.

## What is covered

This repository: the Orca Bot plugin. Problems in OpenMausBot itself belong
with [OpenMausBot](https://github.com/milind-soni/OpenMausBot); problems in
Orca belong with [Orca](https://github.com/stablyai/orca).

The README's [Security review](README.md#security-review) describes where your
data goes and the known risks.
