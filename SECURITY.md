# Security

## Reporting a problem

Please do not open a public issue for a security problem. Use **Report a
vulnerability** on this repository's Security tab on GitHub. You should get a
reply within a week.

Say what you did, what happened, and which versions of Orca, Bot Team for Orca and
Hermes Agent you use. Do not include sign-in codes, tokens or private messages.

## What is covered

This repository: the Bot Team for Orca plugin. Problems in Hermes Agent itself belong
with [Hermes Agent](https://github.com/NousResearch/hermes-agent); problems in
Orca belong with [Orca](https://github.com/stablyai/orca).

The README's [Security review](README.md#security-review) describes where your
data goes and the known risks.
